## Introduction

This project consists on a the development of a bioinformatic pipeline for the analysis and design of antimicrobial peptides (AMPs) targeting bacterial proteases. The pipeline is based on structural and sequence information from MEROPS database, and uses Boltz2 to predict binding affinity of AMPs to bacterial proteases. The pipeline is implemented in Python and is designed to be user-friendly and easy to use.
